# FretaGo 🚚

> MVP under development. This project is currently in the building and validation phase.

FretaGo is a platform designed to support freight and delivery operations, focusing on simplicity, scalability, and real-world logistics needs.

## 🚀 Project Status

⚠️ Under active development  
⚠️ Features may change frequently  
⚠️ Initial structure for product validation and portfolio purposes  

## 🎯 Purpose

The goal of FretaGo is to create a modern solution for freight management, helping organize delivery requests, operations, and logistics flow in a simple and efficient way.

## 🛠 Tech Stack

- Ruby on Rails
- PostgreSQL
- Redis
- Sidekiq
- JavaScript
- Docker

## 📦 Features (in progress)

- User authentication
- Freight/delivery management
- Operational dashboard
- Data organization and tracking

## 🧠 Future Improvements

- Marketplace-style matching (drivers and requests)
- Real-time tracking
- Smart pricing logic
- Integration with external services
